# 2026-10-28

## 搭建 kafka-sql-log 项目（D:/Kafka）

- 目标：每秒写 10 条「SQL 语句(key, String) + 耗时(value, float)」到 Kafka topic `sql-log`。
- 结构：Maven（Java 17 编译目标，kafka-clients 3.7.1 + logback 1.5.6 + junit5，shade 打 fat jar，finalName=kafka-sql-log.jar）。
  - `SqlLogProducer`：按纳秒排程匀速发送、send 回调计数、shutdown hook flush+close（CAS 防重复关闭）、`app.max-records` 上限、`app.dry-run` 无 broker 自测。
  - `SqlLogConsumer`：FloatDeserializer、手动提交位点、5 秒窗口统计、wakeup + latch 优雅退出。
  - `AppConfig`：application.properties → `-Dapp.*` / `-Dkafka.*` → 命令行 key=value 三级覆盖；`kafka.` 前缀剥离后直接喂客户端。
  - `SqlLogGenerator`：6 个 SQL 模板 + 各自耗时区间，自增 id 保证 key 唯一。
- 决策：日志/异常文案用英文（Windows GBK 控制台下中文会乱码），代码注释与 README 用中文。
- 验证：`mvn clean package` 通过（3 个单测）；dry-run 实测约 100ms/条；本机无 9092 broker、无 docker，故未做端到端联调，附 docker-compose（apache/kafka:3.7.1 KRaft）供用户自测。

## 在本机安装并启动 Kafka（20:15-20:20）
- 环境：无 Kafka、无 Docker daemon（只有 CLI），JDK17 在 D:\JDK17。
- 安装位置 `D:\kafka-4.4.0`（不用 D:\kafka：Windows 路径大小写不敏感，会和项目 D:\Kafka 撞）。
- 版本 kafka_2.13-4.4.0，清华 TUNA 镜像下载（130MB，很快）。
- 配置 `config/server-local.properties`：单机 KRaft（broker+controller，node.id=1），log.dirs=D:/kafka-4.4.0/data，num.partitions=3，auto.create.topics.enable=true。
- 格式化：`bin/kafka-storage.sh format -t <uuid> -c config/server-local.properties --standalone`（4.4 必须带 --standalone，否则报错要求 --initial-controllers）。
- 启动踩坑（重要，下次直接绕）：
  1. 宿主进程环境块有大小写重复键（HTTPS_PROXY/https_proxy），导致 PowerShell 的 Env provider 和 Start-Process 全部报"已添加项"；-UseNewEnvironment 也无效。
  2. WMI Win32_Process Create 被安全策略拦截；从 Bash 调 cmd.exe 也被拦截。
  3. 可行方式：Bash 工具 run_in_background 直接跑 java（task uo4ztA）；用户侧常驻入口是 `start-kafka.bat` 双击。
  4. log4j2 配置必须写 `file:/D:/...` URI，写 `D:/...` 报 Invalid URL、日志不落盘。
- 已建 topic `sql-log`（3 分区，RF=1）。端到端验证：producer 跑 6s + 4s 共 100 条，分区偏移 24/47/29；broker 4.4 与项目里的 kafka-clients 3.7.1 兼容。

## 新增 SqlLogConsumer.java（23:25）
- 用户要求加一个"最简单"的消费者类，并把常用消费者 properties 都用上。
- 写法与 producer 同风格：单文件、默认包、System.out.printf、shutdown hook 调 close()。
- 用到的配置：fetch.min.bytes=1024、fetch.max.wait.ms=500、max.partition.fetch.bytes=1MB、
  session.timeout.ms=10000（注释说明不能小于 broker 的 group.min.session.timeout.ms=6s）、
  auto.offset.reset=earliest、enable.auto.commit=true、auto.commit.interval.ms=1000、
  partition.assignment.strategy=RangeAssignor（注释对比 RoundRobin）、max.poll.records=500。
- 加了一行可选参数：args[0] 可覆盖 group.id，方便换组验证 earliest。
- 验证（23:24，topic 当时 150 条）：同 group 二次消费 0 条（自动提交生效）；新 group demo-group-2 从头读出全部 150 条（earliest 生效）。
- 运行方式：IDEA 直接跑 main，或 `mvn compile exec:java -Dexec.mainClass=SqlLogConsumer`。
